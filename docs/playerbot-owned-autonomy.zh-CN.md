# Playerbot 独立登录、离线托管与决斗实验

本发行版在上游 Playerbots 行为之外增加了四项个人服务器功能。实现位于
`patches/0003-playerbot-owned-autonomy-and-duels.patch`，升级 Playerbots 时会由 CI 自动检查补丁兼容性。

## 登录模式

原有命令保持不变：

```text
.playerbot bot add 角色名
```

机器人登录并自动加入主人的队伍；主人退出时机器人也退出。

独立登录但跟随主人生命周期：

```text
.playerbot bot login-solo 角色名
```

机器人登录后不会自动组队，并启用 `new rpg`；主人退出时机器人退出。

离线托管：

```text
.playerbot bot login-persistent 角色名
```

机器人登录后不会自动组队，并启用 `new rpg`。主人退出后，它会转交给服务器继续更新；主人再次登录时会自动重新取得控制，但机器人仍不会被强制拉入队伍。显式执行下面的命令仍会让机器人退出：

```text
.playerbot bot logout 角色名
```

离线托管只跨越玩家的下线和重连，不跨越整个服务端重启。服务端正常关闭时，托管机器人也会保存并退出。

## 用户固定策略

玩家通过 `co`、`nc` 手工添加或删除的策略会另存为用户覆盖项。在离队等事件重建默认策略后，仍适用于当前环境的覆盖项会重新应用。

```text
/w 机器人名 nc +new rpg,-loot
/w 机器人名 co +aoe
```

以下临时策略不会被固定，以免离队后留下无效的组队状态：

```text
follow, stay, guard, free, move from group, start duel
```

使用 `co !` 或 `nc !` 会同时清除相应状态的用户覆盖项并恢复默认策略。

## botduel 决斗实验入口

先让至少两个同阵营机器人进入队伍并站在允许决斗的野外区域，然后在队伍聊天输入：

```text
botduel
```

系统会选取满足以下条件的机器人，两两发起决斗：

- 存活且未在战斗或决斗中；
- 与玩家处于同一地图；
- 两个机器人属于同一阵营；
- 两个机器人相距不超过 40 码。

该入口复用 Playerbots 已有的决斗接受、目标选择和战斗策略，目的是提供可重复的 PvP AI 试验场。它目前不会额外增强走位；后续可以在这个入口上增加距离控制、绕背、打断和脱离危险区域等策略并做对照测试。

## 首轮验收

1. 给机器人设置 `nc +new rpg` 和一个自定义 `co`，离队后用 `nc ?`、`co ?` 检查仍然存在。
2. 设置 `nc +follow` 后离队，确认 `follow` 不会作为用户覆盖项恢复。
3. 使用 `login-solo`，确认机器人在线但队伍未创建；主人退出后机器人退出。
4. 使用 `login-persistent`，确认主人退出后机器人仍在线活动；主人重连后可以再次邀请和指挥。
5. 组入四个同阵营机器人，在开阔区域输入 `botduel`，确认产生两组决斗且结束后可再次触发。
