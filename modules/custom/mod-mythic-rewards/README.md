# mod-mythic-rewards

`my-az-core` 自有的大秘境个人装备奖励模块。

它由 `mod-mythic-plus` 完成奖励处的一行桥接调用触发，为每名按时完成副本的队员发放一件与层数对应的史诗装备。候选物品来自原版掉落表，并经过职业可用性、最高护甲类型、LFG 职责和当前装备属性倾向筛选；Playerbot 与真人使用同一规则。

默认层数：+1/200、+2/213、+3/219、+4/226、+5/232、+6/239、+7 及以上/245，并分别奖励 20～80 金币。背包已满时通过邮件发放。`mod_mythic_rewards_history` 保证同一副本实例中的同一角色只领取一次。

第一版不会自动替机器人装备物品，也不保证每件奖励都是当前装备的升级；机器人会通过 Playerbot 原有的装备评估逻辑处理背包中的奖励。
