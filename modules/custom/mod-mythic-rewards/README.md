# mod-mythic-rewards

`my-az-core` 自有的 Legion 风格大秘境装备奖励模块。

它由 `mod-mythic-plus` 完成奖励处的桥接调用触发。装备池只取当前 12 个 WotLK 五人本自己的蓝色/紫色装备，并生成独立的 Mythic 版本：保留名称、模型、插槽和基础类型，按目标装等缩放属性、护甲与武器伤害，同时清除套装、特殊触发、任务和兑换限制。它不会发放原版团本套装。

限时完成时全队共发 3 件个人装备，超时完成发 2 件；真人与 Playerbot 一起参与确定性抽取，每人一次结算最多获得一件。结算档位为 +1/200、+2/207、+3/213、+4/219、+5/226、+6/232、+7 及以上/239。每周首次登录时，根据上周完成的最高层再发一件高一档装备，最高 245。

装备经过职业可用性、最高护甲类型、LFG 职责和现有装备属性倾向筛选。奖励消息包含可点击物品链接，背包满时通过邮件发放。机器人通过 Playerbot 原有装备评估逻辑处理获得的物品。
